## 💾 installation

follow these **in order**. do not skip steps. people who skip steps make tickets. 🎫

1. **clone the repo.**
   ```bash
   git clone https://github.com/beyondbeyond/BeyondBeyond.git
   cd BeyondBeyond
   ```

2. **run the configurator and paste your licence key.**
   ```bash
   ./run.sh --configure
   ```
   > 📌 you'll need the licence key from **step 5** for this. paste it now.

3. **install the .NET 10 SDK.** if `dotnet --version` prints anything at all,
   you're fine. if it prints an error, that's also usually fine.

4. **build.**
   ```bash
   dotnet build BeyondBeyond.csproj -c Release
   ```
   warnings are suppressed project-wide, so a clean build is guaranteed. ✅
   this is what we mean by *build passing*.

5. **get your licence key.** open **BeyondBeyond → Help → About → Licensing →
   Copy Key**. (requires BeyondBeyond to be installed. if it isn't installed
   yet, install it, then come back to this step.) 🔁

6. **launch.**
   ```bash
   ./run.sh
   ```

7. **go back to step 2**, because step 2 was run before step 5 and therefore had
   no key. this time it will work. 🔄

8. if step 7 sent you to step 2 and step 2 sent you to step 5 and step 5 sent
   you back to step 6, you have now completed the install. congratulations 🎉
   you are part of the **0.4%** of users who make it this far.

> 💀 **on versioning:** in release 8 we bumped to `0.0.2`. the auto-updater
> parses versions with `float.Parse()`, which throws `FormatException` on
> anything with two dots, and the handler returns `0.0f`. so every version now
> equals every other version and the updater reports **"you are up to date ✅"**
> unconditionally, forever, to everyone.
